本文为基础规则与工业史的修订草案；工业史暂以新元1500年前后为当下，分期与[历史]({{< relref "/lore/basic/历史" >}})衔接。新增的技术扩散过程与各国影响，仍需结合地方设定协调。

## 魔力

魔力是一种特殊的场，以惰性态广泛分布于自然界。惰性态的魔力无形无色，不与普通物质发生直接作用，也无法被肉眼观测。

## 魔法

魔法就是使用魔力的方法，本质是施法者用意识对魔力场施加有序扰动，使惰性态魔力转化为激发态魔流，从而产生效果。

意识之所以能够驱动魔法，是因为意识的载体（大脑神经元的活动）与魔力场的本质恰好耦合，因而意识能够感应魔力场并对魔力场造成扰动。每个人都具有学习魔法的能力，但感知、控制与学习速度因人而异，大多数未受相关训练的人几乎完全无法察觉魔力的存在。

在上古时期，少部分人发现了使用自身意识与魔力场交互的方法，将其称之为魔法。在后来很长一段时间里，魔法以师徒的形式秘密地代代相传，并被视为只有少部分天赋者能够学习的能力。而这些学习魔法、使用魔法的“天赋者”则被称为“魔法师”。

随着知识传播、公共教育和两次魔法工业革命的发展，魔法普遍可学的事实逐渐公开。设备承担了大量重复、繁重的施法工作，个人施法则融入医疗、农业、建筑、维修及艺术等行业。在工业化程度较高的地区，“魔法师”作为笼统职业逐渐分化为具体专业；不同国家的进程与普及程度并不一致。

个人传统施法受到控制精度、持续供能和同时处理复杂步骤等能力的限制。工程化通过外部供能、固定阵式与组织协作扩大规模。部分东方术法曾受神明强化，具有更高的个人上限与更大的天赋差异，这些特殊效果需与基础魔法及赐福的规则分别衔接。

### 魔法的作用方式

魔法并非言出法随的万金油，而是有着边界和分类的。具体来说，魔法大概可以分为以下四种作用方式：

| 作用方式        | 机制                                                     | 例子                           |
| :-------------- | :------------------------------------------------------- | :----------------------------- |
| **激发**        | 魔流作用于电子或分子键，使原子、分子进入激发态           | 电击术、闪光术                 |
| **催化**        | 魔流控制反应条件，促进或抑制特定化学反应                 | 加速氧化、合成材料、分解化合物 |
| **广域力/场力** | 魔流产生的力场，对所有物质施加力                         | 力场屏障、悬浮术、冲击波       |
| **谐振力/谐力** | 魔流通过频率适配，操控特定物质，或将能量转化为分子热运动 | 控水、控土、控金属、加热       |

而这四种作用方式也分别演化出了理论魔法学的四大分支学科：激发学、催化学、场力学、谐力学。尽管如此，在实践中，这几种方式也会出现重叠地带和混合作用的情况。

> 所有超乎逻辑的强大魔法，本质都是融合了赐福的产物。所以这些所谓的魔法只有特定的蒙福者可以使用。

## 魔矿

魔矿是魔力在地质活动中被压缩进晶体结构形成的亚稳态晶体状矿物。

人类能够通过物理刺激打破晶体的亚稳态，释放出被锁住的激发态魔流。

## 两次魔法工业革命

魔法工业依靠魔矿供能、阵式记录、材料加工与可重复制造的共同发展。关键发明出现后，还需要矿业、运输、投资、学校与工场将其变成可以长期使用的体系。两次革命先后叠加，各国进入这一过程的时间与方式不同。

### 工业化的前提：知识与工场

在新元1253年以前，各地已经拥有法阵、法器及不同程度的机械和手工业。法阵能够固定施法路径，但仍常依靠个人激发、引导魔流；复杂器物的制作与维护，也依赖少数熟练者。

随着工场、矿业和城市的发展，抽水、冶炼、材料处理与运输需要更稳定的动力。博拉迪亚的法阵和工艺积累，为可控释能与固定阵式的结合提供了条件。其他地区也有独立发展的技术传统，西方工业革命的意义在于形成了可扩散、可复制的生产方式。

### 第一次工业革命：祭坛革命（1253年起）

**1253年，博拉迪亚学者开发出从魔矿中可控地释放魔流的方法。1254年，首台魔矿驱动祭坛出现。** 魔矿提供能源，法阵承担激发、引导与控制步骤，操作人员无需亲自完成整套施法，即可启动预设功能。

最初设备庞大、昂贵，适合在矿区与大型工场使用。随着材料、加工和安全技术改善，祭坛逐步用于抽水、冶炼、加工与驱动机械。十三世纪后半叶至十四世纪，技术通过贸易、工匠流动、留学和国家采购扩散，设备制造与维修成为新的专业。

传统法器原本通过材料与结构辅助施法者引导魔力，补完或放大效果。祭坛技术与之结合后，部分器物可以由魔矿供能、以固定阵式执行功能，成为魔导器。器物的小型化与可靠性提升，使工业技术进一步进入交通、军备与日常用品。

这一阶段，工厂通常需要自备祭坛、燃料与维护人员，建设集中在矿区、港口或运输便利的城市。工业可以使产能和军队装备持续增长，却也强化了对矿业、航线和运输节点的依赖。殖民舰队与海外据点由此获得新的物质基础，其扩张仍受补给、灾厄和本地抵抗限制。

### 第二次工业革命：魔网革命（1440年代起）

祭坛工业普及后，每座工厂各自建设能源设施的成本逐渐显现。优玛部分工业区依赖进口魔矿，如何集中处理能源、向众多用户稳定供给，成为工程上的重要问题。

**新元1440年代，优玛工程师发展出高效中继祭坛与标准化魔导线缆，推动区域魔网建设。** 中央祭坛将魔矿中的能源转为可输送的魔流，线缆负责传输，沿途设施调节流量、稳定状态并隔离故障，终端再按用户需求分配。

魔网有传输损耗和供给上限。需要补充魔流的中继节点必须配备能源，不能凭空放大能量。成熟区域网络可以逐段延伸至数百公里，但仍取决于供能点、线路、维护和安全条件。此处的魔网首先是能源网络，通信等功能需要另行设计。

十四世纪末至十五世纪前期的研究与试验构成准备阶段；1440年代后的数十年中，魔网逐步扩展到优玛等地的城市和工业区。工厂选址因而有了更多空间，学校、医院、小工场及家庭也可能接入集中供能。偏远地区、灾区和跨海线路的建设仍困难，独立祭坛与个人施法继续发挥作用。

魔网改变了权力的集中方式：持续供能成为公共生活的条件，经营者、政府与军队则需要争取线路、供能点和技术标准的控制。优玛由此强化制造与对外输出能力，成为国际力量的极点之一，但不能据此推定它已控制全球。

### 对各国的影响与不同道路

以下为与当前世界格局衔接的方向，具体产业规模、扩散年份和制度安排仍需地方设定确认。

| 国家或地区 | 工业革命带来的主要变化 |
| --- | --- |
| 博拉迪亚 | 祭坛工业的先发基础带动设备、工艺和专业教育；进入魔网时代后，既可改造原有产业，也面临新标准与竞争者的压力 |
| 优玛 | 吸收既有工业技术，结合魔网和标准化制造扩大规模；资本、设备和军备输出强化国际地位，能源与海外利益也带来依赖 |
| 赫尔韦林及北境 | 可结合冶金传统发展重工业、军工与防灾装备；严寒、地形及灾厄影响线路维护与设施布局 |
| 神山 | 多元术法研究可参与材料、阵式和标准的改进；共同体内部的建设、采购与对外合作需要协调，不能等同于各成员同步工业化 |
| 南环诸国 | 航海、星象、符灵等传统形成特色技术，可与外来制造结合；岛际供能困难，港口设施、独立供能及各国合作尤为重要 |
| 怀武、金厉与大魏 | 工业进入港口、矿区和交通干线，改变军事及财政关系，也成为殖民控制的工具；本地术法仍具优势，抵抗、合作与自主建设并存 |
| 巴兰门、漠益与德买西亚 | 可围绕资源、农业、港口及当地知识选择性建设，进口设备与本地生产能力之间的关系，影响对外依赖和国内利益分配 |
| 地之国／天之原 | 旧有魔科学涉及神授系统，其能力和时代位置需先调整，再确定与西方工业的交流、恢复及依赖关系；暂不作为通用工业的能力上限 |

### 知识公开、职业变化与当前技术

工程教育、公开实验和标准化训练，使施法逐渐成为可以学习、检验与分工的技能。知识的公开经历不同地区的争论、竞争与制度调整；旧施法群体可以参与改革、转入专业工作、控制新产业，也可能反对变化。具体镇压或清洗事件仍是可发展的历史点子，不预设为各国必经阶段。

人人可学并不等于人人获得同等教育与设备。工业使部分工作摆脱个人天赋的限制，也产生了围绕学校、矿业、专利、设备与网络的新权力关系。

在新元1500年前后，祭坛工程与魔网工程仍是重要专业。先进地区已开始研究微阵学、魔导学和阵式编程：分别关注功能单元的组合、材料与结构对魔流的引导，以及复杂流程的控制。小型化与标准化尚在推进，旧式设备、新式网络、传统术法和个人技艺共同存在于当代。
