本文供创作者协调时代背景与国家关系，暂作讨论草案。下文区分已明确的方向与建议中的安排；尚未确定的战争、联盟、技术和殖民细节，不作为正式历史。

## 时代定位：分布式战争与多元抗衡

**当前时代暂以新元1500年前后为当下，按“世界大战时期”构想：魔法工业已改变国际力量的分配，多处战争和政治危机通过航运、资源、金融、技术与殖民关系彼此牵动。** 具体战争起点及各国参战状态尚待协调。分期见[历史]({{< relref "/lore/basic/历史" >}})，两次工业革命分别自1253年和1440年代开始，技术过程见[魔法]({{< relref "/lore/basic/魔法" >}})。

世界大战可以由多个战场和不同目标的战争共同构成：强国争夺交通与资源，殖民地争取自主，地方势力进行内战，各国又介入他国的冲突。各场战争可以先后开始、分别停战，部分地区仍维持和平与日常贸易。需要写出它们之间的实际联系，说明一个地区的行动怎样改变其他地区的选择。

国际格局以多元抗衡为基本方向。**优玛是明确的力量极点之一**；其他国家和组织围绕不同议题合作、竞争，联盟可以交错和变化。技术合作国可能存在领土争端，共同作战的国家也可能争夺殖民利益。其余力量极点及具体联盟暂不预定。

战争的议题包括魔矿产地、魔网与技术标准、港口和交通干线、财政收入、政治主权，以及具有战略价值的术法传承。诸神与灾厄持续影响这些竞争：灾区需要投入防御，神授力量会改变战场条件，开发和战争也可能引发新的灾难。

这是共同的时代背景。具体故事仍可聚焦一座城市、一项工程、一个组织或几个人的生活，无须全部进入同一条战争主线。

## 魔法工业化的不均衡

### 人的力量与神授传统

魔法本身具有普遍可学的基础，个人传统施法的能力有限。工程化使知识能够积累、力量能够复制，并通过设备、能源与组织协作扩大规模。个人施法继续融入各行各业；工业实力也取决于维护、运输、训练和持续生产的能力。

**东方部分国家的术法曾受到神明强化，尤其是怀武与金厉。** 这些传统中的个人能力上限更高，个体天赋差异更大。相关神明如今大多已死去或因东方两大灾厄而离开，但强化后的术法仍然影响当地生活。神授强化如何延续、依附于何种载体、能否传授或工程化，需要在各国具体设定中明确。

这些差异应与魔法普遍可学的基础衔接：基础魔法的学习资格、神授强化的获取条件和实际施法效果，需要分别说明。赐福及神授遗产仍是超凡分化的重要来源。

### 发展程度需要分别考察

各国的魔法工业应从以下方面描述，而非仅赋予单一的高低等级：

| 方面 | 主要问题 |
| --- | --- |
| 能源 | 魔矿、其他供能方式及其运输是否稳定，依赖谁的供应？ |
| 制造 | 能自行生产哪些设备，关键部件和维修是否依赖进口？ |
| 覆盖 | 设施集中在港口、矿区、首都，还是已经进入广泛的日常生活？ |
| 知识 | 谁培养工程师、传播技术，又掌握哪些秘密和标准？ |
| 组织 | 谁筹资、建设、维护与调度，能否长期承担成本？ |

一个国家可以拥有先进军工，却缺乏民用设施；港口可以高度工业化，内地仍依赖个人术法。地方术法也可能在特定环境和用途上具有独特优势，成为本国发展的基础或对外合作的筹码。

### 强大的个人与受殖民的国家

**怀武、金厉和大魏均有部分地区或部分主权遭到殖民控制。** 具体殖民者、范围、方式与历史尚待确定，不据此推定全国均被直接占领。

个人强者可以改变一次战斗，却未必能同时保障国家的粮食、财政、交通、装备补充与多个战场。殖民控制也可以通过港口、矿区、铁路、债务、条约和地方代理人实现。应选择与当地实际条件相符的过程，写清失去了什么权利、由谁实施控制，以及哪些力量支持、抵抗或试图改变它。

强大术法必须产生实际后果，例如提高占领成本、限制殖民者深入某些地区，或迫使其接受让步。本地群体可以有各自的判断与利益，殖民关系也会随着技术、组织和战争形势变化。

## 各国与地区的大致位置

除明确说明的方向外，以下工业状态与国际角色均为结合现有特色提出的建议，供各国作者调整。国家内部应保留地区、阶层和组织之间的差异。

| 国家或地区 | 魔法工业化程度与状态 | 国际位置与主要张力 |
| --- | --- | --- |
| **优玛** | 高度发展，以魔网、标准化制造和广泛使用的工业品见长；全球覆盖与垄断程度待定 | 明确的力量极点。可输出技术、资本和军事力量，同时受海外资源、贸易与国内组织利益制约 |
| **赫尔韦林及北境联盟** | 依托既有冶金传统，建议突出重工业与军事工程，民用覆盖另作说明 | 可成为重要的工业与军事竞争者；北境灾害防御、贵族权力和对外竞争共同影响资源分配 |
| **博拉迪亚** | 已有祭坛工业的先发基础；建议保留成熟产业与技术积累，当前相对地位待定 | 宗教、帝国制度与工业先发优势相互交织，面临新兴强国的竞争，也有自己的扩张或合作选择 |
| **神山** | 建议采用高水平研究与部分先进产业、各成员地区发展不均的格局 | **主要参考欧盟设计共同体体制。** 可在学术、标准、灾厄处置及外交协调中发挥作用；统一政策、成员自主与对外依赖之间存在张力 |
| **南环诸国** | 沿用特色术法先进、工业发展偏科的方向；航运、星象与通信等能力可与外部工业结合 | 海上贸易与交通的重要参与者。三叶、七星和明珠各有制度及诉求，对战争、航线安全和外部合作不必立场一致 |
| **大魏帝国** | 建议为整体工业化较低、港口与内地明显不均；傩仪和地方术法仍深刻影响社会 | 已部分遭到殖民。朝廷、地方势力、商人及术者围绕财政、改革与主权有不同选择；既有术法如何应对新的外部力量，是重要问题 |
| **怀武国** | 整体工业化较低，神授强化的术法传统使个人上限较高；建议部分城市和交通节点率先发展工业 | 已遭殖民，控制范围待定。地方传承、国家建设、抵抗组织与外部势力相互牵动，需解决知识整合及长期供给问题 |
| **金厉汗国** | 整体工业化较低，个人术法及神授传统具有优势；建议发展适合草原环境的移动、分散式装备 | 已遭殖民，控制方式待定。王庭与各部族的利益可能因矿业、交通建设及草场变化而分化；草原机动与地方知识仍有战略价值 |
| **地之国／天之原** | 曾有高度发展的福音系统与魔科学，又经历白色黄昏及技术、魔力禁忌；当代恢复程度待定，不能简单视为从未工业化 | **考虑与某些西方国家形成合作，也可能有殖民经历。** 合作对象、对等程度及社会基础尚未确定；需衔接原有隔绝状态、魔力屏障和对技术的态度 |
| **巴兰门** | 建议依托已有魔石矿脉，发展资源开采、加工及部分工业，具体规模待定 | 可成为资源与区域贸易的重要参与者；本国建设、对外出口、矿区利益及外部介入之间存在矛盾 |
| **漠益** | 暂不定等级；可选择若干与当地条件、知识传统相适应的产业发展 | 古老宗教、城市及部族关系共同影响国家选择；对外贸易、合作与竞争需结合地理和当代资源继续补充 |
| **德买西亚** | 建议保持农业与港口经济的重要地位，在部分区域选择性工业化 | 港口承担贸易与文化交汇，工业收益和建设成本会影响既有等级秩序及地区关系；具体对外依赖程度待定 |

## 地之国的力量尺度与风格调整

地之国旧稿中的部分魔法过强，整体风格与当前世界的近现代社会背景存在距离，需要在后续修订中收束。尤其是无门槛许愿、无冲突地实现众人愿望、泛用的物质与能量转换，以及触及生死轮回等表述，不能直接作为普通魔法或当代个人的通用能力。

修订时应分别说明基础魔法、神授强化与神明权柄，明确资源、设备、适用范围和失败条件。福音系统可以保留为具有特殊历史的神授设施，但其用途、覆盖与代价需要限定；白色黄昏等大规模事件也应交代设施规模、特殊条件和社会后果，避免成为个人随时可复现的力量展示。

保留沉默、赎罪、魔力禁忌与灾后生活的特色，并使其进入当代的生产、治理、对外关系和具体人物处境。对西方的合作及可能的殖民经历，应在力量尺度调整后衔接。本段是修订方向，尚未完成对地方旧稿能力与历史的逐项重写。

## 后续需要协调的问题

- **明确战争之间的联系。** 先选少数主要战场，说明参战者的目标、资源和介入途径，再决定世界大战的范围、阶段及称呼。
- **具体化殖民关系。** 分别确定怀武、金厉、大魏的控制区域与主权限制，避免将不同国家写成同一种遭遇。
- **衔接地之国的历史与当下。** 明确何时、如何恢复对外联系，哪些群体推动合作，技术恢复到了什么程度，再决定是否存在殖民经历。
- **确定区域特色如何参与工业化。** 说明东方强化术法、南环法系及各地赐福能否与设备、公共教育和组织训练结合，让各国拥有继续改变自身位置的可能。
