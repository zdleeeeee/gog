# 摆烂诸神

{{< quote source="——《歧路行歌》佚名" >}}

旅人行于世间，要向那诸神求得答案……

弹竖琴，驻足于博拉迪亚的广场，帝国的旧梦只剩残破的大理石柱看管；

乘雪橇，驰骋于赫尔韦林的荒原，追逐那成群的白日羊消融在晨曦边缘。

拜访天之原的道场，神文在阴阳妖的脖颈上苏醒，如落樱亲吻刀光的决断；

穿梭于怀武的山林，求师竹上的隐客，流转千年的炁传承在一吐一纳之间。

巴兰门的占星师在穹顶下描摹命运的曲线，

漠益的守墓人在黄沙中守护圣火的祭典。

远处的海面，优玛的殖民舰用轰鸣声判决：神已被煅入齿轮，未来将在流水线上重诞！

旷野上，那汗国的骑手却只是轻笑：神仍在风中，随鹰笛声掠过草尖。

德买西亚的梵唱在桨声灯影里弥散，

南环群岛的渔歌飞过了一片片白帆，

大魏的傩面背后一闪而过熟悉的脸……

登上神山，爬下深渊，诸神的语言原来早已听过千遍万遍。

……

世界未曾给予旅人一个答案，

却有人问起旅人的起点与终点。

回头看，

那串长长的脚印来自天边；

转向前，

余晖映照的大地一片灿烂，好远，好远……
